# 终端界面

本轮按照 `emil-design-eng` 的可读性、反馈与克制动效原则重构四个交互页面，视觉沿用本模组的军事终端方向。

| Before（原实现） | After（当前实现） | Why（原因） |
| --- | --- | --- |
| 配置页把 820×450 的内容整体缩小 | 实际 GUI 坐标、自适应列数、搜索和滚动列表 | 保持原始字号与准确的点击区域 |
| 科技树横向展开，选中同时开始拖动 | 纵向研究分支、单独滚动的详情、独立滚动条 | 降低误操作，保持研究条件可见 |
| 手工绘制按钮缺少原版键盘与旁白行为 | 共用 `TerminalButton`，继承原版 `Button` | 保留 Tab、确认键、点击音和旁白 |
| 当前页签以禁用按钮表示 | 当前页签显示绿色边线和底线，禁用状态单独表现 | 区分“已选中”和“不可操作” |
| 各页分别维护颜色和缩字代码 | `TerminalUi` 统一配色、边距、文本省略和面板绘制 | 减少重复；长名称不再缩成小字 |
| 白名单和皮肤操作区拥挤 | 固定底部操作区、窄屏布局和完整名称提示 | 防止内容覆盖操作控件 |

## 代码职责

- `render/ui/TerminalUi.java`：颜色、矩形、窗口、原字号文本、省略号及进度条。
- `render/ui/TerminalButton.java`：标准按钮语义、选中态、图标卡片、提示、旁白与裁剪区域。
- `render/ui/TerminalScroll.java`：每个区域独立的滚动位置、边界及滑块拖动。
- `render/KillstreakTerminalScreen.java`：本地连杀配置草稿、服务端快照、搜索、保存和统一设置入口。
- `render/TerminalSettingsScreen.java`：常规、服务器、客户端与按键四页；具体规则见 [终端设置](TERMINAL-SETTINGS.md)。
- `render/HeadquartersTerminalScreen.java`：研究树、装配、材料详情及服务端操作反馈。
- `render/KillstreakWhitelistScreen.java`：当前世界队友、在线玩家、分页及按名添加。
- `render/OperatorSkinScreen.java`：三个岗位的皮肤预览、文件选择和本地保存。

所有材料扣除、研究限制、连杀获取和队友关系仍由原有服务端协议处理；界面不自行修改这些数据。

## 布局与交互

- 使用 Minecraft 实际 GUI 尺寸布局，面向至少 320×240 的 GUI 画布；不额外缩放整页或字体。
- 配置页根据可用宽度使用一至三列；滚轮、滑块和方向键均可浏览奖励。`Ctrl+F` 聚焦搜索。
- 科技树保留分类与父子连接，沿用终端等级、经验需求的排序；方向键及 Home/End 可浏览研究。
- 详情面板与研究树独立滚动。滚动只改变内容位置，不移动底部行动按钮。
- 白名单窄屏使用页签，宽屏使用双栏。名字与输入内容在刷新和页面重建时保留，输入框可按回车提交。
- 皮肤预览裁剪到自身区域，文件名使用原字号；完整文件名通过悬停提示查看。
- 选中状态、焦点、禁用、保存中及超时均有明确反馈。保存超时保留配置草稿，允许重新提交。

## 动效与资源

鼠标悬停只使用 120 ms 颜色过渡。键盘导航和选中立即反馈，不添加滑入、弹跳、背景模糊或持续扫描动画。
界面使用现有原游戏连杀图标与 Minecraft 字体，不注册全局字体，也不增加大尺寸背景贴图。
已有原生连杀获取提示、核弹 UI、遥控 HUD 及平板表面操作仍使用各自恢复的资源和时序。

新增搜索、空结果与保存超时文案覆盖现有 12 种语言，同时更新科技树操作说明。
NeoForge 源码镜像仍排除 `resources`；语言资源随单独的增量 ZIP 提供。

## 开发预览

`tools/build.ps1 -Offline -Tasks @('-PuiPreview', 'runClient')` 启动隔离预览，在 `build/ui-preview/screenshots/`
导出四个页面的真实 PNG。分别使用 320×240、640×400、960×540 的 GUI 画布与中英文示例。
预览使用示例快照，不连接服务器、不创建世界，也不操作玩家游戏目录。`src/uiPreview` 不进入发行 JAR。
