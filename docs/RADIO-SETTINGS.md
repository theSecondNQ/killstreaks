# 无线电语音与字幕设置排查

## 直接影响播报的设置

| 设置 | 位置 | 影响 |
| --- | --- | --- |
| `originalRadio` | 游戏实例的 `config/killstreakcod-client.toml`，也可在手持终端的客户端设置中修改 | 关闭后不播放无线电，并清理正在播放及排队的字幕 |
| `radioVolume` | 同上，范围 0～1，默认 0.75 | 与原版音量共同作用；为零时语音和对应字幕都会停止 |
| 语音／Voice 音量 | 原版“音乐和声音” | 无线电使用 `SoundSource.VOICE`；为零时跳过语音及对应字幕 |
| 主音量 | 原版“音乐和声音” | 为零时跳过语音及对应字幕；非零时继续控制实际音量 |
| 声音输出设备、系统及应用音量 | 原版声音设置、操作系统音量混合器 | 会影响听到的声音；本模组不能检测操作系统静音，字幕可能仍然出现 |

静音会确认服务端等待中的语音完成消息，避免连杀入场被静音设置卡住。切换设置后不会补播已丢弃的队列。

## 直接影响字幕的设置

| 设置 | 影响 |
| --- | --- |
| `radioSubtitles`（客户端配置，默认 true） | 只控制本模组无线电字幕，不静音 |
| F1／隐藏 GUI | 隐藏字幕；语音继续播放 |
| 手持终端“UI 布局”→无线电字幕 | 位置、宽高、不透明度、置顶会影响显示；不透明度为零或移出屏幕后不可见 |
| 游戏语言及语言资源包 | 决定字幕与人物名称的译文；未提供译文时使用英文回退 |
| GUI 缩放、窗口大小、遥控 HUD 安全区域 | 影响换行、显示位置和可用空间，不改变语音内容 |

**原版“显示字幕”辅助功能不控制本模组的无线电字幕。** 聊天可见性、聊天不透明度也不控制它。原版玩家、生物、环境、天气等音量滑块不直接控制无线电；飞机引擎、射击与装备操作音效使用自己的声音类别，应分别排查。

## 内容选择与正常省略

- 终端阵营选择改变语音路线及字幕中的人物，队友白名单改变友军／敌军呼叫播报。
- 呼叫者本人不接收自己的 `friendly_call`，其他被识别为队友的玩家接收对应播报。
- 击中／未击中反馈冷却为 100 游戏刻，受损反馈为 200 游戏刻，其他同类播报为 8 游戏刻。
- 一次播放一段，队列最多八条；无等待凭据的播报超过 400 游戏刻会过期，同类待播消息会合并。
- 炮艇开始退场后，当前任务的后续普通任务播报会被抑制；新一轮任务响应会重置这一状态。
- 暂停单人游戏会暂停队列推进。死亡、离线、切换世界或玩家实例更换会清理队列和字幕。
- 语音资源、实际选中的音频或字幕映射缺失，会让对应声音或字幕不出现。资源包可以覆盖这些资源；资源重载会清理相关缓存。
- 服务器奖励启用、击杀计数、研究和材料规则不直接静音，但可能使相应奖励或播报事件不再触发。

## 对应源码

- `universal/NativePresentationConfig.java`：客户端开关及音量定义。
- `audio/NativeRadioClient.java`：静音条件、播放队列、清理、实际音频选择及完成确认。
- `audio/NativeRadioSubtitles.java`：字幕映射、F1 和布局控制。
- `audio/NativeAudio.java`：阵营、敌我、反馈冷却及服务端播报发送。
- `render/RadioSubtitleOverlay.java`：普通 HUD 与被接管 HUD 的字幕绘制和渲染状态恢复。

## 1.20.1「有语音、无字幕」兼容修复

Forge／NeoForge 的 `PlaySoundEvent` 允许声音模组替换播放对象。原先代码只读取请求时创建的对象：替换对象实际播放后，原对象可能没有解析出的音频文件，字幕便被跳过。现在观察替换结果，并在客户端刻继续读取最终音频，按实际资源匹配字幕；延后解析时只补上剩余显示时间，不重新抽选台词。

字幕独立监听 HUD 的正常结束事件；HUD 开始事件被取消时，改在该事件的末尾绘制，覆盖本模组遥控 HUD 和其他模组替代 HUD 的情况。绘制时暂时隔离遗留的全局透明度、裁剪、深度和变换，再恢复原状态；玩家主动设置的字幕开关、F1、布局位置及不透明度仍然生效。

字幕表按实际音频直接匹配，不再重复使用阶段索引过滤。资源包中的单条损坏记录只跳过该条；找不到字幕的音频会留下 `[Killstreak radio]` 日志，每次资源重载最多记录 32 种缺失，便于玩家提供相关日志。

当前资源表静态核对：694 条字幕、118 条路线，默认和两阵营全部已配置语音均有字幕。这个结果不能证明报告玩家的模组组合已经复现。发行构建使用真实字幕分别导出普通 HUD、取消原版 HUD、遗留透明度与裁剪状态的 PNG 供人工查看；未新增或运行自动化测试。
