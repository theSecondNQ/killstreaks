# 连杀栏与 HUD 布局

沿用 NeoForge `1.2.0.4361`、Forge `1.2.0.4365`。设置属于本机偏好。

## 连杀栏

入口：**手持终端 → 设置 → 客户端**。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 连杀栏样式 | 默认 | 详细、默认、精简 |
| 自动收起连杀栏 | 开启 | 3 秒无呼叫操作后收为屏幕右侧细条 |

- **详细**：图标、名称、按键、可用次数与击杀／得分进度；研究模式显示预购次数。
- **默认**：图标、左侧击杀／得分竖条、底部奖励库存横条。横条八格，超过八次显示满格，实际库存不受限。
- **精简**：仅显示图标，通过颜色表示是否就绪。

获得奖励、按呼叫键、退出遥控后展开。弹出与收起均为 **180 毫秒 ease-out**，中途反向从当前位置接续；呼叫立即执行。打开菜单或编辑 HUD 时保持展开。原版“失真效果”为零时立即完成变化。

客户端 TOML：`rewardRailStyle = 1`（0 详细、1 默认、2 精简），`rewardRailAutoHide = true`。

## 分组编辑

入口：**手持终端 → 设置 → UI 布局**，或按 **F10**。按键可重新绑定。

| 界面 | 可调整内容 |
| --- | --- |
| 连杀栏 | 三个配置栏位、获得后显示的核弹与额外栏位 |
| 炸弹无人机、巡航导弹、遥控战车、智能投射 | 原 HUD 提供的准星、燃料、缩放、载具耐久、操作提示等分组 |
| 攻击直升机、空中炮艇 | 准星、燃料、成像模式、缩放、耐久、武器信息、航向 |
| 其他提示 | 连杀获取提示、核弹警报、望远镜准星、无线电字幕 |

**平板、侦察手机、无人侦察机雷达、战略轰炸标点界面、手持终端、总部通讯终端不提供布局编辑。** 边框、刻度、装饰文字不再逐项列出。每个分组显示本地化名称，不显示 Java 方法名或资源路径。

1. 第一行箭头选择界面，第二行选择功能分组，也可以直接点击预览中的分组。
2. 拖动调整位置；方向键微调，Shift 为十倍。
3. 输入框设置中心 X/Y、宽、高、不透明度；置顶仅在本模组覆盖层内排序。
4. 按 H 隐藏／显示操作面板。小窗口可滚动，保留原始字号。
5. 重置分组或本页。**保存**写入设置；Esc 或取消丢弃草稿。

### 保存格式

`<游戏目录>/config/killstreakcod-ui.json`

```json
{
  "version": 2,
  "elements": {
    "hud.gunship/group/weapons": {
      "x": -0.02,
      "y": 0.02,
      "width": 0.9,
      "height": 0.9,
      "opacity": 0.8,
      "top": false
    }
  }
}
```

`x/y` 为相对原位置的屏幕归一化偏移；宽高为倍率，不透明度为 0～1。旧版细碎图元和已移除界面的设置不再应用，避免旧设置移动平板或终端。保存前保留 `.bak`，通过临时文件原子替换。取消不改动原文件。手动修改后需重启客户端。

## 调整记录

| Before | After | Why |
| --- | --- | --- |
| 每个刻度、背景、文字各有一个配置项 | 按准星、武器信息、耐久等功能分组 | 减少选择负担，保持组件内部关系 |
| 列表出现 Java 方法名及资源路径 | 十二种语言的简短分组名称 | 直接说明调整对象 |
| 平板和终端也可逐项编辑 | 移除对应入口与平板逐像素变换代码 | 保持这些固定操作界面的结构 |
| 连杀栏只有收起动画，弹出直接跳到终点 | 双向 180 毫秒动画，可中断反向 | 展开反馈与收起一致，操作不延迟 |

## 物品、手臂与战斗效果

- M134 在物品栏直接显示已有 PNG 图标；第一人称隐藏近身炮口火焰与亮光，并从视点八格外开始显示更细的弹迹。远端弹迹密度和其他观察者看到的效果保留。
- 设备、部署与 M134 的手部使用原版宽／细玩家手臂及袖层，映射原手腕轨迹。无畏装甲不再单独绘制源手臂网格。
- 呼叫阶段移除屏幕上下缘状态字幕、连接提示和进度条；原设备动画、黑屏转场和无线电字幕保留。
- 炮艇热诱弹仍使用默认 C 键、三次储备、五秒冷却。按一次后持续五秒从机腹后段左右两侧分批喷射亮点，带源烟雾和下落轨迹；受客户端特效数量上限约束。攻击直升机沿用原规则。
- 巡航导弹对每刻完整路径检查最近方块、实体和旋转后的飞机机体。飞机检查覆盖已加载机体，避免大型机翼远离实体中心时漏检；碰触己方飞机也引爆，但伤害仍受队友保护约束。不可见的电子干扰机没有物理机体。

## 同步与交付

两个源码镜像排除 `resources`。语言更新单独提供 `killstreaks-ui-layout-language-1.2.0.zip`。Forge 构建通过 `-PkillstreakLanguageDir` 读取语言目录。

生产构建、发行静态清单和隔离客户端界面截图分别用于编译、归档及人工布局核对。预览不连接服务器、不创建或读取玩家世界。此次未运行自动化测试；机体碰撞、飞行中热诱弹及手臂实际握持仍需游戏内体验。

详细的新分组、核爆、坠毁与兼容规则见 [本轮改动](COMBAT-REFINEMENT.md)。
