# 操作、战斗与地图兼容更新

版本保持 NeoForge **1.2.0.4361** 与 Forge **1.2.0.4365**。

## 手部、物品及转场

- 原版宽／细手臂和皮肤袖层保留，按源指根推导手掌方向，并以拇指与食指的握持接触点贴合设备。手掌厚度向设备背面补偿，不再只把方块手臂末端放到手腕挂点。
- M134 与哨戒机枪物品栏使用原模型。按旋转后的模型边界居中、等比缩放，不使用源网格的偏置原点；哨戒图标显示完整部署模型，手持时仍显示原携行模型。
- M134 通用射线不再于玩家眼睛处生成重复火焰粒子。本人第一人称隐藏近身炮口、弹壳和炮口亮光，八格外的弹迹更细；其他玩家观察到的原效果保留。
- 普通及遥控 HUD 均在最后绘制呼叫黑屏。自然结束的平板点击动作短暂保持黑屏，直到入场消息接管；取消、死亡及换世界清空过渡状态。

## HUD 布局

平板、手机、侦察雷达、战略轰炸标点及两个终端继续不提供布局编辑。

| 调整前 | 调整后 |
| --- | --- |
| 武器信息合为一组 | 每行武器独立调整，热诱弹另设一组 |
| 飞行数据无法配置 | 呼号、在线状态、机体坐标、速度、高度、航向、俯仰、目标坐标等可配置 |
| 无人机只有准星 | 增加成像、耐久、电量、高度、速度等分组 |
| 操作提示合为一组 | 遥控操作按单个按键提示分组，名称使用现有按键译文 |
| 巡航状态文字固定 | 剩余时间、锁定、武装、武器模式、就绪状态分别可调 |

仍以完整功能行登记，不把边框和刻度拆成碎片。新增名称补入十二种语言。旧的 `weapons`、`controls` 整组覆盖不再影响新分组，其余分组沿用原设置。

## 核爆

- 不再绘制原核爆序列帧图片。三个蘑菇状粒子云由径向渐变粒子几何生成，包括上升茎部、翻卷顶帽及扩散尘环。
- 三个中心点位于呼叫中心半径 **64 格**的同一圆上，间隔 **120°**。
- 正好三枚 MGB 模型分别飞向三个中心点；落弹与粒子云共用 `NuclearPattern`，不再随机落下一堆模型。
- 保留闪光、冲击、声音及既有服务器伤害规则。

## 空战

- 炮艇按一次热诱弹键后持续 **100 游戏刻（5 秒）**喷射，每四刻从机腹后段两侧各发射一批。每批每侧最多十二枚，总量受客户端特效上限约束；侧向速度和存活时间增加，诱导点距离机体更远。
- 炮艇击毁后保持滑翔及缓慢下降，约九秒后空爆；提前撞到方块则在碰撞时爆炸。
- VTOL 与支援直升机持续下坠到方块或水面接触后爆炸，取消原来的定时空爆。坠入虚空时只清理实体。
- 巡航导弹爆炸对范围内自己或敌方的空中连杀执行致命打击，包含原本只接受特定伤害的机种、炸弹无人机及其他巡航导弹；白名单队友仍受保护。伤害配置为零时不会绕过禁伤设置。各机种沿用原摧毁／坠毁流程。

## GD656 得分

得分模式且 GD656 服务端接口可用时，读取其 `PlayerDataManager.get().getScore(UUID)` 的正向增量：

- 两个已安装版本 **NeoForge 1.1.0.020**、**Forge 1.3.2** 的接口均已核对。
- 本模组不再额外叠加固定 125／25 分；击杀数和核弹击杀门槛仍单独结算。
- 包含 GD656 实际授予的击杀、额外加分、助攻等分数。小数分保留到足够一分再结算。
- 登录时建立基线，离线清理；已有累计分不会在登录后转成奖励。扣分或外部分数重置不倒扣已获得的连杀。
- 不读取客户端显示文字、不接收客户端报分、不修改 GD656 数据。接口不兼容时记录日志并回退原固定得分。

## 地图兼容

平板标点和侦察地图优先复用当前世界已有地图瓦片，顺序为 JourneyMap、Xaero World Map、独立 Xaero Minimap、VoxelMap。没有可用瓦片的像素回退本模组地形图；标记、选点、坐标和服务器验证保留。

| 地图 | 接入方式与核对依据 |
| --- | --- |
| JourneyMap | 当前维度的 RegionImageCache／ImageHolder 已渲染图像；本地 Forge 6.0.7 JAR 接口 |
| Xaero World Map | 已上传的 64 格区域纹理，跟随纹理版本刷新；官方分发 NeoForge 1.21.1 1.47.0 JAR 接口 |
| Xaero Minimap | 已渲染 MinimapChunk 纹理；官方分发 NeoForge 1.21.1 26.6.0 JAR 接口，独立安装也有适配路径 |
| VoxelMap | 当前世界 CachedRegion 的原像素数据；[项目源代码](https://github.com/fantahund/VoxelMap/tree/master/common/src/main/java/com/mamiyaotaru/voxelmap/persistent) |

窗口快照缓存 750 毫秒。GPU 读回每个游戏刻最多四块，并缓存地形瓦片；独立 Xaero Minimap 瓦片至多约十秒刷新一次。纹理绑定、像素打包参数和 PBO 绑定均恢复，不切换帧缓冲，不改动其他模组设置或键位。

只读取当前已渲染数据，不强制其他模组打开地图、生成地图或扫描新区块。新地图、未探索区域、未上传纹理和不兼容版本使用回退地形；服务器标点范围不会因外部地图扩大而放宽。

## 交付范围

两个平台编译、资源静态清单与隔离客户端的模型图标、源手部动作、核云、HUD 预览分别核对。预览不读取玩家存档。未执行自动化测试；带地图模组的实际选点、GD656 多人计分、飞行中热诱弹、伤害与坠毁仍需世界内体验。

源码分别同步 Forge 1.20.1 与 NeoForge develop，排除 resources。语言资源另行打包；两个生产 JAR 继续控制在 100 MB 以下。
