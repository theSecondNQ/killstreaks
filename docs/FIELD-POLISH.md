# 握持、坠毁、M134 与空投调整

版本保持 NeoForge 1.21.1 **1.2.0.4361**、Forge 1.20.1 **1.2.0.4365**。

- **握持接触面**：原版宽／细手臂和袖层沿用源动作。以源手指的握持面方向计算方块手掌厚度和末端位置，接触点位于手掌外表面，并保留约 0.6 厘米间隙；去掉固定摄像机深度偏移。
- **支援机坠毁**：垂直起降战机和支援直升机的水平速度、下降速度、下降加速度及转向速度均减半，碰到方块或水面才爆炸。保存时的坠毁时钟校验同时适配更长的下落时间及炮艇原有滑翔时间。
- **坠毁火光与烟雾**：所有 `crash_` 特效在各自原有倍率之上再放大两倍；弹片模型、粒子数量上限和伤害独立保留。摄像机近处仍保留防止整屏遮挡的尺寸限制。
- **M134**：原开火阶段在实际 `tag_flash` 绘制小型原资源枪焰，侧面与正面均可见，图集只采样单格。椭圆弹迹从每次发射时的动画炮口汇聚到服务端命中点，发射后保持世界坐标，不再附着当前枪口随视角转动；旁观者弹迹也从源炮口挂点出发。保持原碰撞线、伤害、射速和蓄转时间。
- **空投**：普通空投和紧急空投的箱体不再绘制原导入模型或备用模型的降落伞，去掉恒定缓降，使用原版重力直接落下。无畏装甲箱保留原来的降落伞和缓降。
- **语音设置排查**：见 [语音与字幕设置说明](RADIO-SETTINGS.md)。本次只增强配置注释和说明，不改写玩家音量或字幕开关。

两个平台进行生产编译、资源清单核对及隔离客户端的手部／M134 模型预览。预览不读取玩家存档；没有新增或运行自动化测试。实际坠毁和空投落地表现仍需世界内体验。

源码同步到 Forge 1.20.1 分支与 NeoForge develop，排除 resources。此次沿用已有贴图，没有新增资源文件。
