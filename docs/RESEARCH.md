# 总部终端研究系统

依据更新后的《新系统.docx》及后续规则修订实现。当前版本为 **1.2.0.4361**，包含 20 项基础研究（含核弹）、59 项升级，共 79 个节点及四级终端。新增连杀、费用与武器操作见[火力与现代化研究](RESEARCH-EXPANSION.md)。原 `terminal.obj`、MTL 及九张 PNG 保持原样。

## 从终端开始

合成并放置“总部通讯终端”，右键打开科技树。顶部按钮查看终端升级费用或切换玩法模式。左侧的侦察、支援、火力、现代化四个分类均已接入研究条目。

各分类内的连杀与升级按“所需终端等级→研究所需经验等级”升序排列；两项要求都相同时保留原顺序，存档节点名称及内部位序不变。在画布内拖拽平移，滚轮上下滚动，Shift＋滚轮左右移动。点击节点后，右侧显示说明、终端等级、前置研究、储备次数、可呼叫次数、获取门槛、材料持有量和经验等级。右侧费用面板也能独立滚动，低分辨率下可查看完整内容。

升级研究完成后默认装配。再次点击已研究的升级，可在右侧免费“装配升级”或“卸下升级”，无需重复支付材料或经验。节点分别标明“已装配”和“已卸下”；卸下保留研究成果与完成度。装配状态在生存、连杀两种模式中共用，并应用于后续部署，正在执行的任务保留生成时的升级快照。

材料从背包和副手扣除，不读取末影箱、不扣穿戴中的装备。经验费用按等级扣除。服务端先核对全部条件，再一次性完成扣款和解锁；未满足条件的请求不会部分扣款。研究和终端等级跟随当前世界内的玩家，不跟随某一块终端；多人共用方块时各自操作自己的研究。

## 两种玩法模式

- 新玩家处于原版生存或冒险模式时，默认使用模组生存模式。先研究连杀、加入便携终端的三个配置栏位，并在总部终端“预购一次”支付材料储备次数。之后按原击杀／得分门槛消耗储备并获得可呼叫奖励；未研究或没有储备的奖励不累计获取进度，已有部分进度保留。
- 新创造玩家默认进入连杀模式，也可以自由切换模式。在终端内可免费研究、免费升级或一键全部解锁。创造模式呼叫也需要已有次数，可通过创造栏的连杀物品或管理指令发放。
- 生存模式下，“储备次数”表示已支付材料、尚待击杀／得分解锁的次数；“可呼叫次数”表示已经达标的奖励。每次达标同时扣一次储备、加一次可呼叫库存；重复获取规则关闭时，每种奖励仍仅能在一条命内获取一次。总部终端和原呼叫快捷键均只消耗一次可呼叫库存，不再检查或扣除背包材料；材料不足只影响预购。
- 额外奖励继续使用原额外奖励栏位，空投保留随机提供未研究连杀的流程；已有库存和奖励凭证保留。
- 新玩家完成四级终端及全部 79 个研究节点后，开放连杀模式。进入后仍通过击杀／得分获得奖励，呼叫无需材料，已装配升级照常生效。卸下升级不会取消资格；旧版已通过完成研究获得的连杀模式资格保留。
- 首次升级安装的旧模组世界默认保留连杀模式。旧版本玩家标签和世界队友文件用于首次识别，之后保存明确的研究状态。
- 旧存档玩家一旦主动切换至生存模式，就需要完成研究后才能再次进入连杀模式；创造模式仍可自由切换。研究不会因死亡、重登、换维度或拆除终端而丢失。

服务端已有的计分、重复获取、核弹及无畏装甲开关继续生效。生存模式右侧连杀栏显示可呼叫库存、击杀／得分进度及预付储备。连杀模式不需要预购，也不会消耗已有储备。

例如预购 2 次无人侦察机：储备为 2、可呼叫为 0；完成 4 次击杀后，储备变为 1、可呼叫变为 1；按呼叫键后可呼叫变为 0，背包材料不再变化。重复获取开启时，再完成 4 次击杀可将最后一次储备转为奖励。核弹仍独立按 30 次直接击杀获取，不占三个配置栏位。

预付储备不因死亡、重登、换维度、模式切换或拆除终端而消失。普通进度重置、死亡重置不清除储备；管理命令 `resetall` 会一并清除储备、已获得奖励和额外奖励。旧版已有可呼叫库存继续有效，不补扣材料；旧存档的预付储备初始为 0。

`config/killstreakcod-server.toml` 的 `[research].disableUpgrades` 默认 `false`。开启后，禁用升级研究、装配及两种模式中的升级效果，保留已有研究进度和装配选择；禁用期间以终端IV级及全部20项基础研究作为连杀模式的完成条件。重载规则及持续状态处理见[禁用升级项目](RESEARCH-EXPANSION.md#禁用升级项目)。

### 本阶段采用的具体口径

- 高级空投奖励按原系统10杀档及以上处理，概率提高为原概率的1.25倍，最高100%，不是增加25个百分点。
- 监视者计划按当前血量减半，一次呼叫只触发一次；它不直接击杀目标。普通侦察保留原有地表和遮挡检测，无所遁形是独立的范围高亮升级。
- 末影侦察跳过实体与航线空间检查，仍维持原有下界空中连杀禁用规则。
- 干扰阻止新的奖励激活和部署，不强行切断已有遥控会话。
- 技能效果使用任务生成时的装配快照；临时切换模式、后来研究或装卸升级，不会追溯改变已部署单位。哨戒拾取再放置沿用剩余时间和原有升级，避免重复增加续航。
- 副职提供的空投和支援直升机明确关闭升级继承，避免递归派发空投或无限延长支援。

## 存储与源码

研究保存在当前世界的 `data/killstreakcod_research.dat`，按 UUID 分开。解锁、装配和维修状态使用稳定节点名称，运行及同步快照采用固定长度的128位选择。世界数据升级为Schema 4，原有38项节点位序保持不变。装配状态随研究保存，死亡、重登或切换模式均不清空。旧研究存档没有装配名单时，保持全部已研究升级为装配状态；“一键全部解锁”不会重新装上玩家主动卸下的升级。旧版通过研究取得的模式资格单独保留。预付储备以稳定奖励 ID 存在每个玩家的 `Requisitions` 中，与已解锁库存分开；原 Schema 3 及更早的研究、装配和模式资格继续读取。现有奖励库存、阵营及队友文件继续由原模块管理。

| 类 | 职责 |
| --- | --- |
| `ResearchCatalog` | 费用、节点、类别及稳定节点名称转换 |
| `HeadquartersResearchData` | 世界数据、玩家研究、预付储备、旧世界识别 |
| `ResearchSystem` | 服务端预购及储备扣除、研究、升级装卸、呼叫、模式与菜单校验 |
| `ResearchEffects` | 任务升级快照、虚拟侦察、干扰和支援效果 |
| `ResearchMask` | 固定128位不可变选择及有界网络编解码 |
| `ResearchCombat` | 装甲、减伤、声波、化学云与电子压制 |
| `ResearchOrdnance` | 额外架次、钻地弹、附加武器及自主导弹 |
| `ResearchActionPayload`、`ResearchStatePayload` | 有长度限制的操作及状态同步 |
| `HeadquartersTerminalScreen` | 科技树、费用详情、条件及操作按钮 |

网络操作必须对应玩家正在使用的总部终端菜单，并通过距离、存活和频率检查。创造权限由服务端确认，不采纳客户端提交的价格、玩家 UUID 或已解锁状态。

新增界面提供简体中文、繁体中文、文言和英文文字；新增预购按钮、储备数量和操作结果另补齐全部12种语言；其余研究条目在非中英文语言下继续使用英文回退，已有界面和字幕翻译保留。
