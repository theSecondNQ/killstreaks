# 总部终端研究系统

依据工程根目录的《新系统.docx》及后续规则修订实现。当前版本为 **1.1.0.4341**，包含 9 项连杀研究、29 项升级和四级终端。原 `terminal.obj`、MTL 及九张 PNG 保持原样。

## 从终端开始

合成并放置“总部通讯终端”，右键打开科技树。顶部按钮查看终端升级费用或切换玩法模式。左侧有侦察、支援、火力、现代化四个分类；目前火力、现代化没有研究条目。

各分类内的连杀按所需终端等级从低到高排列，各连杀的升级也按等级升序排列；同级条目保留原顺序，存档节点名称及内部位序不变。在画布内拖拽平移，滚轮上下滚动，Shift＋滚轮左右移动。点击节点后，右侧显示说明、终端等级、前置研究、已获得次数、获取门槛、材料持有量和经验等级。右侧费用面板也能独立滚动，低分辨率下可查看完整内容。

材料从背包和副手扣除，不读取末影箱、不扣穿戴中的装备。经验费用按等级扣除。服务端先核对全部条件，再一次性完成扣款和解锁；未满足条件的请求不会部分扣款。研究和终端等级跟随当前世界内的玩家，不跟随某一块终端；多人共用方块时各自操作自己的研究。

## 两种玩法模式

- 新玩家处于原版生存或冒险模式时，默认使用模组生存模式。先研究连杀并加入便携终端的三个配置栏位，再按原击杀／得分门槛获得真实奖励次数；未研究的普通奖励不累计获取进度。
- 新创造玩家默认进入连杀模式，也可以自由切换模式。在终端内可免费研究、免费升级或一键全部解锁。创造模式呼叫也需要已有次数，可通过创造栏的连杀物品或管理指令发放。
- 生存模式下，总部终端和原呼叫快捷键共用校验：需要完成基础研究、有已获得次数，并备齐呼叫材料；每次消耗一次库存及对应材料。只有材料不能生成呼叫次数；材料不足不会扣除库存。
- 额外奖励继续使用原额外奖励栏位，空投保留随机提供未研究连杀的流程；已有库存和奖励凭证保留。
- 四级终端及全部 38 个研究节点完成后，开放连杀模式。进入后仍通过击杀／得分获得奖励，呼叫无需材料，新呼叫不应用研究升级。
- 首次升级安装的旧模组世界默认保留连杀模式。旧版本玩家标签和世界队友文件用于首次识别，之后保存明确的研究状态。
- 旧存档玩家一旦主动切换至生存模式，就需要完成研究后才能再次进入连杀模式；创造模式仍可自由切换。研究不会因死亡、重登、换维度或拆除终端而丢失。

服务端已有的计分、重复获取、核弹及无畏装甲开关继续生效。右侧连杀栏恢复显示真实库存和击杀／得分获取进度，不再把“材料足够”显示为库存。

### 本阶段采用的具体口径

- 高级空投奖励按原系统10杀档及以上处理，概率提高为原概率的1.25倍，最高100%，不是增加25个百分点。
- 监视者计划按当前血量减半，一次呼叫只触发一次；它不直接击杀目标。普通侦察保留原有地表和遮挡检测，无所遁形是独立的范围高亮升级。
- 末影侦察跳过实体与航线空间检查，仍维持原有下界空中连杀禁用规则。
- 干扰阻止新的奖励激活和部署，不强行切断已有遥控会话。
- 技能效果使用任务生成时的研究快照；临时切换模式、后来解锁升级，不会追溯强化已部署单位。哨戒拾取再放置沿用剩余时间，避免重复增加续航。
- 副职提供的空投和支援直升机明确关闭升级继承，避免递归派发空投或无限延长支援。

## 存储与源码

研究保存在当前世界的 `data/killstreakcod_research.dat`，按 UUID 分开。解锁和维修状态使用稳定的节点名称存储，避免后续插入研究条目时错位。现有奖励库存、阵营及队友文件继续由原模块管理。

| 类 | 职责 |
| --- | --- |
| `ResearchCatalog` | 费用、节点、类别及稳定节点名称转换 |
| `HeadquartersResearchData` | 世界数据、玩家研究、旧世界识别 |
| `ResearchSystem` | 服务端购买、呼叫、模式与菜单校验 |
| `ResearchEffects` | 任务升级快照、虚拟侦察、干扰和支援效果 |
| `ResearchActionPayload`、`ResearchStatePayload` | 有长度限制的操作及状态同步 |
| `HeadquartersTerminalScreen` | 科技树、费用详情、条件及操作按钮 |

网络操作必须对应玩家正在使用的总部终端菜单，并通过距离、存活和频率检查。创造权限由服务端确认，不采纳客户端提交的价格、玩家 UUID 或已解锁状态。

新增界面提供简体中文、繁体中文、文言和英文文字；其余语言本阶段使用英文新增条目作为回退，已有界面和字幕翻译保留。
