# 空中炮艇与攻击直升机 HUD

当前 `1.1.0.4352` 已接入 `aircraft_hud_index` 提供的原始贴图、控件布局和已核对的数值动画。适用空中炮艇、攻击直升机的遥控画面及攻击直升机座舱三块显示屏。

## 导入内容

| 数据 | 接入方式 |
| --- | --- |
| 32 张原始 PNG | 按导出清单核对 SHA-256，保留原分辨率与像素；已有相同文件直接复用 |
| 46 个控件构造关系 | 保留锚点、偏移、子控件、默认透明度和旋转 |
| 1,306 条数值动画通道 | 读取已核对的属性通道及各序列毫秒长度 |
| 66 组原版中英文文字 | 增补语言键；繁中与文言由模组译写，其他语言暂用英文 |
| 3 块座舱画布 | 左屏 256×256、中央屏 512×512、右屏 256×256 |

运行清单为 `src/main/resources/assets/killstreakcod/mw/aircraft-hud-ui.json`。纹理位于清单中的 `texture` 路径，新增图像放在 `textures/gui/mwii/aircraft`。构建与游戏运行不需要访问 MW2022 导出目录。

导入工具仅解析 JSON 与受限的数值算术表达式，不执行重建的 Lua。原生 LUI 的完整控制流、字体、着色器、最终 HUD 遮罩和屏幕投影并未恢复；本次接入已确认的布局和动画数据，文字继续使用 Minecraft 字体。

## HUD 与实际状态

- 炮艇按当前武器切换 25、40、105 毫米准星，保留开火、切换及装填时的状态变化；弹药来自实际库存，研究扩展武器继续显示。
- 攻击直升机分别显示机炮、火箭弹、剩余时间、生命值、诱饵弹和实际绑定按键。
- 坐标、高度、航向、俯仰与速度来自当前 Minecraft 任务状态，单位使用格／米与米每秒。目标位置沿当前瞄准方向采样，每四个游戏刻更新一次。
- 低燃料、严重损伤和损伤裂纹按实际状态显示。当前协议没有来袭导弹信息，因此不无条件播放原资源中的导弹警报。
- 原控件包含多人／单人、观战、键鼠及手柄等不同分支；常规遥控画面只启用对应控件。
- 获取提示、连杀栏、其他遥控奖励及既有操控方式不受这套布局入口影响。

布局以原 1920×1080 画布为基准，按 GUI 高度统一缩放偏移，保留原锚点。子控件可超出父容器：例如炮艇武器栏高度仅为 26，内部弹药行仍使用原偏移，不能按这个高度再次压缩。GD656 占用区域参与生命值／武器栏避让，字幕同时避开 GD656 和当前飞机 HUD 的信息区域。

`GunshipControls.BootUp` 的 7,300 毫秒是属性通道长度，不是整段入场视频的实测时长。HUD 保留装饰层的启动变化，不额外等待 7.3 秒才显示可用武器和操控。原 HUD 的 2°／80°仅用于刻度映射，实际视场仍由遥控逻辑控制。

## 座舱显示屏与缓存

`NativeChopperScreens` 将原背景、中央旋转准星和箭头、右屏闪烁图层合成到原生尺寸画布，按现有任务阶段处理 `Normal`、`Crashing` 和 `Hide`。动态贴图每两刻更新一次；不在光影渲染过程中切换自定义帧缓冲。

生命值的原 `mask` 贴图是不透明模板输入，不能直接作为透明图层覆盖屏幕。当前使用透明轮廓与辉光裁剪显示实际生命值。未恢复的引擎模板与专用着色器不作伪装实现。

`NativeSceneUi` 缓存布局和动画通道，飞机 HUD 的混合状态按整次绘制保存一次。资源重载、离开遥控和退出世界通过现有重置入口清理状态及动态纹理。若新清单或其中图像缺失，保留原有 HUD 回退路径。
