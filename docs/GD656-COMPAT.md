# GD656 中文配置编码兼容

GD656 的预设包使用 UTF-8。部分版本通过没有指定字符集的 `FileReader(File)` 和 `FileWriter(File)` 读写 `element_config.json` 与客户端配置。当 JVM 默认编码与 UTF-8 不同时，中文可能变成其他汉字或问号，并在保存设置时再次写入错误文本。

本轮检查中，First Light 实例现有配置的 UTF-8 中文原文完整；GD656 使用 Minecraft 自带字体，模组没有覆盖它的字体或语言命名空间。兼容修正针对配置的字符集，不改写显示文本。

## 接入方式

- `Gd656ConfigEncodingMixin` 只替换 GD656 两个客户端配置管理类中依赖默认字符集的文件读写构造器，显式使用 UTF-8。
- 已经明确指定编码的读写不受影响。新版 GD656 调整实现或移除这些构造器时，注入允许零匹配。
- `OptionalMixinPlugin.getMixins()` 在客户端且目标类存在时动态注册，不提前加载目标类。未安装 GD656 或运行专用服务端时，不注册这项兼容。
- 动态注册沿用已有兼容配置插件，因此两个平台只同步 Java 源码也能接入，无需复制 `resources` 中的 Mixin 配置。

核对的 NeoForge GD656 1.1.0.020 包存在默认编码的读取及写入；Forge GD656 1.3.2 的部分读取已明确编码，仍存在默认编码写入。两种情况使用同一项按构造器签名匹配的兼容。

## 保留数据

本次不重置或重建 GD656 的预设、布局、外部贴图与音效。已有正确 UTF-8 配置在下次启动时按原文读取，后续保存使用相同编码。

若其他实例的文本已经被保存成错误汉字或问号，指定字符集不能推断丢失的原文；需要从该实例的备份或原预设恢复，不能对所有中文自动作反向转码。

## 安装与核对

安装工具识别原 `killstreakcod-*` 文件名及新的平台文件名。更新后统一使用 `killstreaks-neoforge-1.21.1-<版本号>.jar` 或 `killstreaks-forge-1.20.1-<版本号>.jar`；旧包先备份，并拒绝同一实例内的重复模组文件。

本轮验证范围为两端 Java 编译、兼容目标字节码签名及资源／配置文件静态核对；不将这些结果当成游戏内文字显示已通过验证。
